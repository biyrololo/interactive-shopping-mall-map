📋 Архитектура и оптимизация (Раздел 4 ТЗ)

1. Оптимизация рендеринга текстовых подписей при 1000+ текстурированных объектах

Рендеринг 1000 отдельных DOM-элементов или индивидуальных тяжелых текстур вызывает перегрузку. Для поддержания стабильных 60 FPS применяются:

  • SDF (Signed Distance Field) / MSDF Font Atlas: Весь алфавит запекается в один атлас текстур. Все 1000 подписей отрисовываются как геометрия через единый InstancedMesh всего за 1 Draw Call на GPU.
  • Frustum & Distance Culling: На каждом кадре скрываются подписи, находящиеся вне пирамиды видимости камеры или дальше порогового радиуса.
  • LOD (Level of Detail) & Decluttering: При отдалении камеры показываются только якорные магазины, подписи бутиков скрываются до приближения зума.

2. Обработка кликов и Raycasting при объединенной геометрии (InstancedMesh / BatchedMesh)

  • InstancedMesh Raycasting: Метод raycaster.intersectObject(instancedMesh) возвращает intersection.instanceId. Это позволяет мгновенно по индексу за \(O(1)\) достать метаданные магазина из массива без разбиения меша.
  • GPU Color Picking: Рендеринг сцены во внеэкранный буфер 1x1 пиксель под курсором с уникальным RGB-цветом для каждого ID. Считывание gl.readPixels работает за \(O(1)\) вне зависимости от количества полигонов в сцене.

3. Структура хранения данных в JS для быстрого поиска по ID и координатам

  • Поиск по ID: Map<string, PlaceData> — хэш-таблица обеспечивает мгновенный доступ со сложностью \(O(1)\).
  • Поиск по координатам (X, Z): Spatial Hash Grid (2D Grid Index) или 2D Quadtree / R-Tree (RBush). Плоскость делится на ячейки. Координаты математически мапятся в ключ ячейки за \(O(1)\), проверяя только 1-2 объекта внутри ячейки вместо обхода всех 1000 элементов.

4. Описание алгоритма размещения без пересечений

Использован алгоритм рядов торговых галерей с динамическим шагом (см. src/layout.js):

  • 100 магазинов упорядочиваются по рядам (по 10 магазинов в ряду).
  • По оси X магазины следуют с технологическим зазором 1.2 м.
  • По оси Z ряды разделены пешеходным проходом 3.5 м с учетом максимальной глубины ряда.
  • Автоматический тест checkCollisions гарантирует математическое отсутствие пересечений (0 коллизий).
